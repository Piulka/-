# Сторонние компоненты

## scrcpy server 5.0.1

`tools/scrcpy/scrcpy-server` — сервер проекта [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy), распространяемый по Apache License 2.0. Текст лицензии: [tools/scrcpy/LICENSE](tools/scrcpy/LICENSE).

Сервер включён как ресурс для USB-потока Android. Десктопный бинарник scrcpy и сторонний бинарник ADB в репозиторий не входят; ADB выбирается из установленного Android SDK или другого локального расположения.

Иконка и логотипы в `Assets/` созданы встроенным imagegen для этого проекта; исходные промпты лежат рядом с изображениями.
