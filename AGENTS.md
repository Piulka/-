# Работа с Жмякее

Перед первой правкой прочитай `PROJECT_CONTEXT.md` и относящиеся к задаче разделы `README.md`. Это основной контекст передачи проекта между агентами; сверяй его с текущим кодом и Git.

- Общайся с пользователем по-русски, очень компактно. Сразу сообщай результат; не пересказывай ход работы и весь контекст.
- Обычные правки выполняй самостоятельно до проверяемого результата. Уточняй только существенные неизвестные. Не запускай параллельных агентов без явного запроса пользователя.
- Секреты, номера аккаунтов, OTP, cookies, токены, сертификаты подписи и реальные захваты экранов не добавляй в Git, исходники или логи. Не извлекай данные входа из браузерных профилей.
- Для админки и сброса OTP поддерживается только test08; настройки города — только Калуга, 590, тип Courier. Расширяй область только по прямому запросу пользователя.
- «Сохранить» в админке сохраняет настройку БЕЗ сброса кэша. GO + PHP сбрасываются отдельной кнопкой.
- Настоящий видеоповтор iPhone — отдельное окно. Не возвращай проксирование кликов с перемещением курсора, миганием и перестановкой окон или удалённую функцию связывания окон.
- Используй существующую постоянную подпись macOS через `build.sh`/`sign-local.py`. Не меняй bundle ID и не сбрасывай разрешения TCC без необходимости.
- Проверяй по существу изменённый механизм. После изменения исполняемого кода собери приложение; перед перезапуском убедись, что нет записи, установки или авторизации. Не трогай прочую работу пользователя на устройствах.
- UI управляй разрешённым инструментом компьютерного управления. Ограничения инструмента и отказы безопасности не обходи альтернативными средствами.
- Коммиты допустимы для завершённых правок. Пуш, публикацию и другие внешние записи выполняй по запросу пользователя; не делай force-push.
